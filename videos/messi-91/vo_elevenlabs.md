# Messi's 91: ElevenLabs voiceover script

**Model:** Eleven v3 (it understands the [emotion] tags). Older models ignore tags, so delete them there.
**Voice:** a British male narrator or pundit voice (calm by default, with range). Stability: around "Natural" or a little toward "Creative" for more emotion.

**How to export (easiest):** generate each numbered line as its own clip, download them as `01.mp3`, `02.mp3` … `12.mp3`, and upload all of them.
The build trims the silence and syncs each beat exactly, so pauses don't matter.

**Alternative:** paste everything as one block and export one file. Keep a blank line between lines so there's a clear pause.
